# Static Deployment

The builder produces a self-contained static directory and does not need a server, database, account system, or build framework.

Open `dist/index.html` locally for a quick check. To share a phone-friendly link, upload the complete `dist/` directory to any static-file host that supports HTML, CSS, and external HTTPS assets, such as GitHub Pages, Vercel, Netlify, Cloudflare Pages, or another equivalent service. Keep the relative directory structure intact. Deployment credentials and publishing are outside this Skill unless the user explicitly asks for them.
